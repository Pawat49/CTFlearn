# Suspicious Message

## Description

Hello! My friend Fari sent me this suspicious message: `MQDzqdor{Ix4Oa41W_1F_B00h_m1YlqPpPP}` and `photo.png`. Help me decrypt this!

![Suspicious Photo](/Suspecious/photo.png)

## Solution

The message can be decrypted using the Playfair cipher.

1. Navigate to the [Rumkin Playfair Cipher Tool](https://rumkin.com/tools/cipher/playfair/).
2. Enter the ciphertext `MQDzqdor{Ix4Oa41W_1F_B00h_m1YlqPpPP}` along with the appropriate key derived from `photo.png`.
3. Decrypt the message to reveal the flag.

![Decryption Screenshot](/Suspecious/Screenshot%202026-05-27%20133324.png)

## Flag

`CTFlearn{Pl4Yf41R_1S_C00l_c1PheRrRR}`
