# CTFlearn Challenges

Welcome to the CTFlearn repository! This repository contains a collection of Capture The Flag (CTF) challenges from CTFlearn, covering various topics like cryptography, forensics, and basic programming.

## Challenges

Here is a list of the challenges included in this repository:

* **[Suspecious](./Suspecious/):** A cryptography challenge involving the Playfair cipher.
* **[Tone dialing](./Tone%20dialing/):** An audio analysis challenge dealing with DTMF tones.
* **[exif](./exif/):** A forensics challenge where you need to examine the EXIF data of an image.
* **[hex](./hex/):** A basic programming/scripting challenge related to hexadecimal conversions.
* **[vignere-Cipher](./vignere-Cipher/):** A cryptography challenge focusing on the Vigenère cipher.
* **[wow...so meta](./wow...so%20meta/):** A forensics challenge involving metadata extraction from images.
* **[zero-or-one](./zero-or-one/):** A programming challenge dealing with binary data.

## Structure

Each challenge directory typically follows this structure, as outlined in the `README.md` template:

* `## Description`: Provides a summary or the prompt for the challenge.
* `## Solution`: Explains the steps taken to solve the challenge.
* `## Flag`: The final flag obtained upon solving the challenge.

Feel free to explore the individual challenge directories for more details and their respective solutions. Happy Hacking!
